# GPT Image 2 常见问题解答（FAQ）

## 基础问题

### GPT Image 2 是什么？

GPT Image 2 是 OpenAI 于 2025 年发布的最新图像生成模型。它采用自回归架构，能够根据文字描述（Prompt）生成高质量图片。相比前代 DALL-E 3，GPT Image 2 在真实感、文字渲染和中文理解方面有显著提升。

### GPT Image 2 和 DALL-E 3 有什么区别？

| 对比项 | GPT Image 2 | DALL-E 3 |
|--------|-------------|----------|
| 发布时间 | 2025 年 | 2023 年 |
| 图像真实感 | 照片级 | 良好但有 AI 痕迹 |
| 文字渲染 | 精准可读 | 较好但偶尔出错 |
| 中文理解 | 原生支持 | 有限支持 |
| 分辨率 | 最高 4K | 最高 1024×1024 |
| 生成速度 | 约 10 秒 | 约 15-20 秒 |

详细对比请参阅 [模型对比分析 →](comparison.md)

### GPT Image 2 免费吗？

是的。gptimgtwo.com 提供免费生成次数，注册即可使用，无需绑定信用卡或手机号。免费次数用完后可选择付费套餐。

### 支持中文提示词吗？

完全支持。GPT Image 2 对中文有原生理解能力，可以直接用中文描述你想要的图片，不需要翻译成英文。中文提示词的生成效果与英文相当。

### 怎么写好提示词？

核心原则是**具体、详细、有结构**。一个好的提示词包含：主体、环境、光影、风格四个要素。

详见 [Prompt 写作指南 →](prompt-guide.md) 和 [提示词模板库 →](../prompts/)

### 支持哪些图片尺寸？

| 比例 | 分辨率 | 适用场景 |
|------|--------|---------|
| 1:1 | 正方形 | 头像、产品图、Instagram |
| 16:9 | 横版 | 网页 Banner、视频封面、PPT |
| 9:16 | 竖版 | 手机壁纸、抖音封面、小红书 |
| 4:3 | 标准横版 | 网页插图、印刷品 |

### 最高支持多大分辨率？

最高支持 4K（4096px）分辨率。日常使用 1K-2K 即可满足网页和社交媒体需求，需要印刷或大屏展示时建议使用 4K。

### 支持哪些艺术风格？

- 油画
- 水彩
- 3D 渲染
- 赛博朋克
- 极简主义
- 波普艺术

### 图片中可以有文字吗？

可以。GPT Image 2 的文字渲染能力相比前代有质的飞跃，图片中的中英文文字清晰可读。你可以直接在提示词中指定文字内容。

示例：
```
一个咖啡杯放在木质桌面上，杯身上写着 "Good Morning"，
旁边有一本翻开的书，暖色调自然光，照片级真实感
```

## 技术问题

### 为什么生成失败？

可能的原因：
- 提示词包含受限内容
- 服务器繁忙，请稍后重试
- 网络连接不稳定

### 为什么生成速度慢？

正常生成时间约 10 秒。如果超过 30 秒：
- 4K 分辨率生成时间会更长
- 服务器高峰期可能需要排队
- 建议刷新页面重试

### 支持手机使用吗？

支持。网站采用响应式设计，手机浏览器直接访问即可正常使用所有功能。

### 需要安装什么软件吗？

不需要。直接在浏览器中打开 gptimgtwo.com 即可使用，支持 Chrome、Safari、Firefox、Edge 等主流浏览器。
