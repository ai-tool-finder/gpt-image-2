# 快速上手指南

本文将带你从零开始使用 GPT Image 2 在线生成 AI 图片。全程不超过 2 分钟。

## 注册账号

1. 打开 [www.clamflow.asia](https://www.clamflow.asia)
2. 输入邮箱和密码
3. 点击注册
4. 注册成功后自动获得免费生成次数

> 无需绑定信用卡，无需手机号。

## 开始生成图片

### 1. 进入生成页面

登录后点击导航栏「生成」。

### 2. 编写提示词

在输入框中用文字描述你想要的图片。中文、英文均可。

**好的提示词要素：**

| 要素 | 作用 | 示例 |
|------|------|------|
| 主体 | 画面的核心内容 | "一只橘猫" |
| 动作/姿态 | 主体的状态 | "趴在窗台上晒太阳" |
| 环境 | 背景和场景 | "窗外是樱花树" |
| 光影 | 光线氛围 | "午后阳光斜射" |
| 风格 | 整体画风 | "照片级真实感，浅景深" |

**示例提示词：**

```
一只橘猫趴在木质窗台上晒太阳，窗外是盛开的粉色樱花树，
午后阳光透过玻璃洒在猫身上，形成温暖的光斑，
照片级真实感，35mm 镜头，浅景深，暖色调
```

### 3. 选择生成参数

| 参数 | 选项 | 推荐场景 |
|------|------|---------|
| **风格** | 写实 / 数字艺术 / 动漫 / 油画 / 水彩 等 | 根据需要的画面风格选择 |
| **尺寸** | 1:1 / 16:9 / 9:16 / 4:3 | 1:1 适合头像，16:9 适合横版，9:16 适合手机壁纸 |
| **分辨率** | 1K / 2K / 4K | 网页用 1K 即可，印刷或大屏建议 4K |

### 4. 点击生成

点击「生成」按钮，等待约 10 秒。生成完成后图片会自动显示。

### 5. 下载图片

对结果满意即可直接下载。不满意可以修改提示词重新生成。

## 常用技巧

1. **多试几次**：同样的提示词每次生成的结果不同，多生成几次选出最好的
2. **逐步细化**：先用简短提示词看大致效果，再逐步添加细节关键词
3. **参考提示词模板**：[提示词模板库](../prompts/) 中有分类整理好的提示词，直接复制使用
4. **切换语言**：页面右上角可切换中英文界面
