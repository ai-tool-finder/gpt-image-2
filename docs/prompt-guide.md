# GPT Image 2 Prompt 写作指南

好的提示词（Prompt）是生成高质量 AI 图片的关键。本指南从基础到进阶，帮助你掌握 GPT Image 2 的提示词写作技巧。

---

## 基础原则

### 提示词结构

一个完整的提示词通常包含以下要素，按重要程度排列：

```
[主体] + [动作/姿态] + [环境/背景] + [光影] + [风格/氛围] + [技术参数]
```

不需要每次都包含所有要素，但要素越多、描述越具体，结果越可控。

### 核心技巧：具体胜过抽象

```
❌ 一座美丽的城市
✅ 上海外滩夜景，陆家嘴天际线倒映在黄浦江中，
   远处东方明珠塔灯光璀璨，蓝紫色暮光天空，长曝光摄影风格
```

---

## 六大写作要素详解

### 1. 主体描述

主体是画面的核心。描述时注意：
- **种类和外观**：品种、颜色、材质、服饰
- **数量和位置**：几个、在哪里、相互关系
- **表情和动作**：情绪、姿态、朝向

```
一位 25 岁的中国女性，齐肩短发，穿白色衬衫，
微笑着看向镜头，双手自然交叠放在桌上
```

### 2. 环境与背景

环境决定了画面的故事感和氛围。

```
❌ 在咖啡店
✅ 在东京的一家复古咖啡店，木质吧台，墙上挂着黑胶唱片，
   暖黄色吊灯，窗外是下着小雨的街道
```

### 3. 光影描述

光影是区分"还行"和"惊艳"的关键。

| 关键词 | 效果 |
|--------|------|
| 自然光 / 柔光 | 柔和均匀，适合人像 |
| 黄金时刻 (golden hour) | 暖色调，长影子，适合风景 |
| 逆光 / 轮廓光 | 勾勒轮廓，适合氛围感 |
| 电影灯光 | 戏剧性对比，适合故事感 |
| 霓虹灯光 | 赛博朋克/夜生活氛围 |
| 伦勃朗光 | 经典人像布光，三角光斑 |

```
午后自然光从左侧窗户照入，在脸上形成柔和的明暗过渡，
背景虚化，温暖的色调
```

### 4. 构图与视角

| 关键词 | 效果 |
|--------|------|
| 特写 (close-up) | 面部或物体细节 |
| 半身 (half-body) | 腰部以上 |
| 全身 (full-body) | 完整人物 |
| 俯视 (bird's eye view) | 从上方看 |
| 仰视 (low angle) | 从下方看，显得高大 |
| 平视 (eye level) | 自然视角 |
| 对称构图 (symmetrical) | 平衡稳定 |

### 5. 风格关键词

#### 照写实风格
```
照片级真实感，8K 超高清，35mm 镜头，f/1.8 浅景深，
RAW 格式质感，专业摄影
```

#### 动漫/二次元风格
```
日系动漫风格，京都动画质感，细腻上色，
柔和光影，背景虚化，新海诚风格天空
```

#### 中国风
```
水墨画风格，宣纸质感，留白构图，
淡雅色调，传统中国绘画意境
```

#### 3D 渲染
```
3D 渲染，C4D 风格，柔和材质，
圆角设计，糖果色配色，Isometric 视角
```

#### 赛博朋克
```
赛博朋克风格，霓虹灯，雨夜，高对比度，
紫色和青色调，未来都市，全息投影
```

### 6. 质量提升词

在提示词末尾加上这些关键词可以提升整体质量：

```
超高细节，8K 分辨率，专业级画质，锐利清晰，
大师级作品，exquisite detail, masterpiece, best quality
```

## 进阶技巧

### 负面提示词思维

虽然 GPT Image 2 不直接支持负面提示词，但你可以通过正面描述来规避不想要的效果：

```
❌ 不要模糊
✅ 锐利清晰，高解析度

❌ 不要太暗
✅ 明亮通透，光线充足
```

### 分步细化法

第一步 — 简单提示词看方向：
```
一只猫在窗台上
```

第二步 — 添加主体细节：
```
一只毛色蓬松的橘猫趴在木质窗台上
```

第三步 — 添加环境：
```
一只毛色蓬松的橘猫趴在木质窗台上，窗外是春天的花园
```

第四步 — 添加光影和风格：
```
一只毛色蓬松的橘猫趴在木质窗台上，窗外是春天的花园，
午后阳光透过玻璃洒在猫身上，照片级真实感，浅景深，暖色调
```

### 中英文混合技巧

GPT Image 2 同时理解中英文，可以混合使用以获得最佳效果：

```
中国古镇的清晨，石板路上有薄薄的晨雾，
一个穿汉服的女子撑着油纸伞走过石桥，
cinematic lighting, shallow depth of field,
照片级真实感，电影级构图
```

## 常见问题

**提示词需要多长？**
一般 1-3 句话效果最好。太短则不够具体，太长可能导致模型抓不住重点。

**中文和英文哪个效果更好？**
GPT Image 2 对中文有原生支持，效果相当。中英文混用也可以。

**为什么同样的提示词结果不同？**
AI 图像生成具有随机性。如果第一次不满意，可以多生成几次选择最好的。

**可以生成名人或品牌相关图片吗？**
请遵守相关法律法规和 OpenAI 使用条款，不要生成侵权内容。
