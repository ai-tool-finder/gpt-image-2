## GPT Image 2 是什么？

GPT Image 2 是 OpenAI 于 2025 年发布的最新一代图像生成模型。它采用自回归架构，能够根据文字描述（Prompt）生成高度逼真的图像。相比上一代 DALL-E 3，GPT Image 2 在以下方面有显著提升：

- **照片级真实感**：生成的图像在细节、光影、材质上接近真实照片

- **快速生成**：平均 10 秒内完成一张图

## Prompt 写作技巧

写好 Prompt 是生成高质量图片的关键。以下是核心原则：

### 1. 明确主体

```
❌ 画一只猫
✅ 一只毛色蓬松的布偶猫，蓝色眼睛，优雅地坐在窗台上
```

### 2. 描述环境和背景

```
❌ 猫在窗户边
✅ 猫坐在落地窗旁，窗外是雨后的城市夜景，霓虹灯光映在玻璃上
```

### 3. 指定风格和氛围

```
✅ 电影级光影，35mm 镜头，浅景深，暖色调，柔和自然光
✅ 宫崎骏动画风格，清新水彩质感，蓝天白云
✅ 赛博朋克风格，霓虹灯，雨夜，高对比度
```

### 4. 加入细节关键词

```
✅ 8K 超高清，精细纹理，皮肤毛孔可见，头发丝分明
✅ 极简主义，留白，莫兰迪配色
```
